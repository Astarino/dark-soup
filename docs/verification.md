# Проверки рефакторинга

## Повторяемые проверки

```sh
npm test
npm run check
```

21 тест проходит без браузера, Canvas и DOM. Проверены:

- базовый урон, множитель и округление, минимальный урон, отбрасывание громилы;
- смерть и выдача опыта/счётчика убийств ровно один раз;
- бессрочное горение, повторное применение без сброса таймера, несколько тиков за шаг, прекращение урона после смерти;
- контактный урон и неуязвимость;
- лечение, ранги/пределы, бонусы, первый таймер моркови, уникальность вариантов;
- несколько уровней за одно начисление, остаток опыта, последовательный выбор улучшений;
- падение моркови и однократный удар, активация/перезарядка капусты, интервалы ударов лука;
- первые враги, масштабирование здоровья и минутная орда;
- геометрия мира и столкновения без графики;
- допустимые переходы, пауза, перезапуск, смерть перед повышением уровня;
- невозможность изменить живое состояние через снимок;
- ключи/значения сохранений, отказ хранилища, полнота переводов.

`check` проверяет синтаксис JS и направления импортов. Он также запрещает браузерные зависимости в механиках. Это не заменяет полноценную проверку типов, ревью и браузерный тест.

## Сравнение с исходным кодом

`tests/fixtures/original-runs.json` содержит эталонные состояния из **0c4603d**, до рефакторинга. Для каждого начального ингредиента использованы фиксированная случайность, движение по окружности, вид 1200×800, 7200 шагов по 1/60 секунды и автоматический выбор первого доступного улучшения. В точках 1, 10, 30, 60 и 120 секунд сценария сравниваются все данные игрока, врагов, опыта, ударов, волн, частиц, текстов, камеры и состояния. Если забег закончился раньше, последующие точки проверяют поведение после поражения.

Все три сценария совпали полностью, включая координаты и численные значения с плавающей точкой. Проверка не использует заново реализованную модель ожидаемого поведения. Для аудита оставлен `scripts/capture-original.js`: он извлекает исходный код из зафиксированного коммита через Git и воспроизводит эталон. Не регенерировать fixture, чтобы скрыть регрессию. Для обычного `npm test` Git и исходный коммит не нужны.

Отдельная браузерная проверка: в одном Chromium, с одинаковым размером окна, RNG seed 100, фиксированными часами, загруженными шрифтами и 600 кадрами после выбора моркови сравнивались RGBA-пиксели Canvas исходной и новой версии. Размер буфера — 640×289; обе версии дали SHA-256:

```text
fd9f8092c688b763d4e02e831c9767a31f5daa5b024a7e9bd78954c995761e42
```

Это подтверждает идентичность конкретного кадра, а не всех возможных сцен/браузеров. Временные страницы с исходной игрой удалены после сравнения.

## Браузер

Проверено в Chromium на десктопе (1280 CSS px) и в эмуляции iPhone 14 (390 CSS px):

- начало, первая добавка, цифровые клавиши;
- WASD/стрелки, сенсорный джойстик и `pointercancel`;
- Esc/P, кнопка паузы, неизменность игрового времени на паузе, продолжение;
- перезапуск с обнулением характеристик и таймеров;
- RU/EN, сохранение языка, возврат из настроек;
- книга, предыдущая/следующая/последняя страницы, закрытие через Esc;
- две страницы на десктопе и одна на мобильном экране;
- экран поражения, четыре блока статистики, запись рекорда и повторный старт.

Сценарий основных экранов сохранён в `scripts/browser-smoke.js`. Он выполняется **в браузере**, не через Node, и использует DOM-события клавиатуры/указателя. Для повторения с установленным `agent-browser`:

```sh
agent-browser --session soup-check open 'http://localhost:5173/?debug'
agent-browser --session soup-check eval --stdin < scripts/browser-smoke.js
agent-browser --session soup-check set device 'iPhone 14'
agent-browser --session soup-check reload
agent-browser --session soup-check eval --stdin < scripts/browser-smoke.js
agent-browser --session soup-check close
```

`agent-browser` не является зависимостью проекта. Можно пройти тот же список вручную. Используйте отдельный профиль: сценарий меняет сохранённый язык. При автоматизации через агента сначала загрузите инструкцию установленной версии CLI.

Проверены HTTP-выдача HTML/ES-модулей новым Node-сервером, MIME JavaScript, отсутствие кэширования и синтаксис macOS-лаунчера. Для игры оставлен также запуск через Python.

## Сохранённые особенности и ограничения

- Порядок систем и случайных вызовов сохранён. Косметические эффекты пока используют тот же поток случайности, что и бой; разделение RNG изменило бы последовательности существующего поведения. Эталонные тесты фиксируют RNG только внутри своего процесса и восстанавливают его после проверки.
- Горение бессрочное, не складывается и не сбрасывается при повторном контакте. Орда может превышать обычный лимит врагов; размер вида влияет на точки появления. Эти особенности не исправлялись как часть рефакторинга.
- Дельта кадра теперь неотрицательна: timestamp `requestAnimationFrame` может немного отстать от сброшенного через `performance.now()` таймера. Верхний предел 0,05 секунды прежний. Дополнительно `applyUpgrade` отвергает неизвестные записи и превышение ранга, которые нормальный UI и раньше не предлагал.
- Прямой `file://`-запуск заменён локальным HTTP из-за ES-модулей. Старый порт и ключи localStorage сохранены. Данные между разными origin не мигрируют; исходного сохранения забега не было.
- Реальные iOS/Android, Safari/Firefox и длительные нагрузочные прогоны на слабом телефоне не проверены. Эмуляция не заменяет проверку физического касания, safe-area и производительности устройства.
- Внешние Google Fonts оставлены как в исходной игре; офлайн может использоваться другой запасной шрифт.
